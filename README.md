# Rapha Lashes

Sistema de gestão para estúdio de design de cílios.

## Funcionalidades
- Agenda inteligente sem conflitos de horário
- Cadastro completo de clientes com histórico de atendimentos
- Lembretes automáticos via WhatsApp
- Dashboard financeiro com indicadores de faturamento

## Tecnologias utilizadas
- Front-end: React.js / Vue.js
- Back-end: Node.js / Django
- Banco de dados: PostgreSQL
- API de mensagens: WhatsApp Business API
